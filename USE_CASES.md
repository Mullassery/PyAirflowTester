# PyAirflowTester - Use Cases

## Overview

Static analysis, dependency intelligence, and risk scoring for Airflow DAGs and dbt projects. > **Not to be confused with [PyDBTGuard](https://github.com/Mullassery/PyDBTGuard) or [PyBeamGuard](https://github.com/Mullassery/PyBeamGuard):** PyAirflowTester validates Airflow DAGs (and dbt runs); PyDBTGuard analyzes dbt manifests; PyBeamGuard analyzes Beam/Dataflow pipelines.
