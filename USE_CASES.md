# PyAirflowTester - Use Cases

## Overview

Static analysis, dependency intelligence, and risk scoring for Airflow DAGs and dbt projects. > **Not to be confused with [PyDBTGuard](../PyDBTGuard) or [PyBeamGuard](../PyBeamGuard):** PyAirflowTester validates Airflow DAGs (and dbt runs); PyDBTGuard analyzes dbt manifests; PyBeamGuard analyzes Beam/Dataflow pipelines.
